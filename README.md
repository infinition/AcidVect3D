# AcidVect3D

[![License](https://img.shields.io/badge/License-MIT-yellow.svg)](LICENSE) ![JavaScript](https://img.shields.io/badge/JavaScript-F7DF1E?style=flat&logo=javascript&logoColor=black) [![Release](https://img.shields.io/github/v/release/infinition/AcidVect3D?style=flat)](https://github.com/infinition/AcidVect3D/releases) [![Buy Me a Coffee](https://img.shields.io/badge/Buy%20Me%20a%20Coffee-ffdd00?style=flat&logo=buy-me-a-coffee&logoColor=black)](https://buymeacoffee.com/infinition)

A browser-based editor that takes SVG files and turns them into 3D models ready for 3D printing. Import an SVG, extrude it, adjust depth and scale, export as STL or GLB.

Live: https://infinition.github.io/AcidVect3D/

<img width="1982" height="1248" alt="AcidVect3D interface" src="https://github.com/user-attachments/assets/43e4022a-ff29-4dfb-bdf9-370c06962c4b" />

---

## Usage

Open `index.html` or use the live link. No installation required.

Import an SVG file, set the extrusion depth and other parameters, preview the 3D result in the viewport, then export.

---

## Stack

- Three.js for 3D rendering
- Tailwind CSS (CDN)
- Vanilla JS, no build step
